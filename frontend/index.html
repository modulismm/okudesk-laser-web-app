Why this project exists

Cette interface existe parce que le workflow macOS original pour l’Oku Desk a été abandonné. Des usagers se sont retrouvés sans outil fiable, maintenu, ni support adéquat.

  • Abandon du logiciel macOS (NomadTech) et absence de maintenance à long terme.
  • Manque de soutien aux usagers et frustration face à un outil “boîte noire”.
  • Manque de respect quand les utilisateurs deviennent dépendants d’un workflow qui disparaît.

Notre objectif: un workflow transparent, reproductible, documenté, et maintenu par la communauté.

Crédits / inspirations: on reconnaît explicitement les projets dont nous nous sommes inspirés, notamment les extensions Inkscape NomadTech (GPL) et les projets amont cités dans leurs en-têtes (Nick Drobchenko, hugomatic, Aaron Spike, TurnkeyTyranny, etc.).
